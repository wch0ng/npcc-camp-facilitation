# NPCC Camp Facilitation

Interactive companion for learning camp facilitation (React + Vite + Tailwind, installable PWA). Built from a copy of the LMSC v2 app.

- **Learn**: 8 modules: The Camp Facilitator, Leading an Activity, Risk Assessment (RAMS), Facilitation, Suggested Questions, Roles & Conduct, Running Camp Games, Building on LMSC.
- **Practice**: flash cards and camp scenarios.
- **Games**: a library of camp games adapted for NPCC, with safety notes and debrief questions.

The notes have no scenarios, so `src/data/scenarios.js` holds situations written for the app. They only apply frameworks from the notes.

## Acknowledgement

Some content is adapted from camp facilitator training materials from SIT SSO 2016.

## Run

```
npm install
npm run dev
```

Not hosted yet. `reference/` is git-ignored: the source notes are not for publishing.
